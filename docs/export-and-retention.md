# 图纸导出与文件保留策略（M8）

## 正式数据源

每个 PNG 和 PDF 都关联到唯一的 `PatternVersion`。效果 PNG、编号网格 PNG、网页预览、PDF 网格和材料合计都从该版本的正式网格与材料清单生成，不允许在导出阶段重新推断颜色或数量。

PDF 包含作品信息、完整效果预览、按最多 35×35 分页的坐标网格、颜色编号、材料清单、总数核对和制作建议。优先嵌入配置的中文字体；本地 macOS 使用系统中文字体，Linux 部署建议配置 Noto Sans CJK。没有可嵌入字体时使用 PDF 标准中文 CID 字体并在导出元数据中明确记录。

## 删除策略

用户删除首版采用软删除：作品立即从图纸库和所有用户端详情/导出入口消失，数据库版本、审计和文件暂不物理删除。这样可以处理误删、额度争议和生成事故排查。

正式部署可增加定时清理：软删除 30 天后再次检查是否存在申诉、审计保留或共享引用；没有引用时先删除对象存储文件，再删除数据库记录。清理任务必须记录对象键、版本和执行结果，并支持失败重试。首版不在用户请求线程直接删除文件。

## 运营审计

会员、功能、色板、模型调用和生成张数均可在 Django Admin 查看。管理员调整周期总张数会自动创建 `adjust` 台账，记录调整前后、操作者和时间。配置修改创建递增的新版本；运行中的生成任务继续使用创建时保存的配置快照。
