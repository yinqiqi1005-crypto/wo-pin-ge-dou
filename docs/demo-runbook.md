# 作品集演示手册

## 准备

1. 执行迁移、`seed_demo_config` 和 `prepare_demo --password ...`；
2. 使用 `demo_registered`、`demo_plus`、`demo_pro`，免费游客保持未登录；
3. 素材位于 `media/demo-assets/`；
4. 打开 Django Admin 备用页签，展示会员张数、模型路由、任务、调用日志和张数台账。

## 正常流程（约 4 分钟）

1. 用注册会员上传 `demo-person.png`；
2. 说明前台只有可理解阶段，后台保存结构化主体与推荐参数；
3. 选择 30×30、12 色并生成，展示效果、编号网格、材料清单和制作建议；
4. 保存后导出 PDF，展示坐标分页和材料合计；
5. 用 Plus 从旧版本做风格转换，说明内容型创作成功使用 1 张、旧版本仍可查看；
6. 免费调整尺寸，展示新参数版本不使用张数；
7. 在 Admin 查看任务使用的会员/模型配置快照、模型耗时和张数台账。

## 异常恢复（约 2 分钟）

1. 把测试路由指向故障提供者或运行自动化故障用例；
2. 图片分析失败时展示规则降级且不使用张数；
3. 高级创作失败时展示有限重试、旧版本保留、预留释放；
4. 展示最近任务入口，说明用户离开进度页后仍可恢复；
5. 展示超大/损坏文件的就近错误提示。

## 公网发布后冒烟

```bash
uv run python manage.py smoke_deployment \
  --base-url https://demo.example.com \
  --expected-host demo.example.com \
  --report docs/deployment-smoke/production-2026-08.json
```

报告必须由真实公网域名生成，且不得覆盖旧报告。在 7 天内将该文件传给 `check_release_quality --deployment-report`；命令会再次核对 HTTPS、同域名和全部安全项，不接受手填的 `passed`。仅有本机 Gunicorn 测试不能替代这一项。

## 面试讲解重点

- 为什么放弃点数，改成用户可直接理解的“张数”；
- 为什么 AI 输出不能直接成为正式图纸；
- 为什么预留与最终使用必须分开；
- 为什么基础能力允许规则降级，而高级内容生成不能静默降级；
- 如何用配置快照解决排队任务和后台改价/改模型之间的一致性；
- 哪些验证是自动化的，哪些（真实拼豆制作和外部部署）仍需要现实世界执行。
